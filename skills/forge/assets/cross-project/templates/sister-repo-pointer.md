# Cross-Project Coordination

This repo participates in cross-project FORGE coordination.

- Authority repo: `<repo-name-or-url>`
- Coordination docs: `docs/forge/cross-project/`
- Read first: `COORDINATION.yaml`
- Then read: relevant `contracts/` docs and active `decisions/XPD-*` files
  that list this repo in `affects` or `review_requested_from`

Do not change authority-owned shared contracts unilaterally. Propose changes
through the authority repo's `inbox/` unless the user explicitly instructs
otherwise.
